# CoC 职业目录

职业选择器和主持人工具集的「职业与技能参考」共用一个可搜索目录。可按名称、技能或 `#编号` 搜索，也可按来源筛选。选择结果后先查看职业点公式、信用范围和技能说明，再点击「使用此职业」。

## 覆盖范围

按用户提供的《COC七版空白自动卡.xlsx》「职业列表」A4:G232 整理，共 229 项预设，编号 2–230。编号 0 是清空提示，编号 1 是自定义入口，不计入预设。原有 37 个模板继续放在「原有模板」筛选中，旧卡按原定义读取。

| -------- | ------------------------------------------- | ---- |
| 2–115    | 基础职业                                    | 114  |
| 116–156  | 调查员伴侣                                  | 41   |
| 157–169  | 日本秘史                                    | 13   |
| 170–204  | 克苏鲁 2010／克苏鲁与帝国／克苏鲁 2015 合集 | 35   |
| 205–230  | 克苏鲁煤气灯                                | 26   |

来源分区按原表 H 列标记和分区边框确定。日系合集未逐项注明所属扩展，不推断更细的出处。煤气灯分区的年代标签与表内维多利亚时代说明不一致，因此目录不复述其年代数字。这是参考卡的整理结果，不表示所有扩展均为七版基本规则；扩展条件由主持人审核。

## 数值与兼容处理

- 每项职业保留原始编号、名称、信用上下限、公式、G 列技能原文。角色通过 `cocCareer.occupationId` 保存稳定编号；同名的基础职业与煤气灯职业不会互相覆盖。无编号的旧卡继续使用原有模板。
- 同一职业族的变体仍可通过「启用职业分支」切换，分支和技能专长开关互相独立；也可从完整目录直接选中具体职业。职业族是查找方式，分支使用对应条目的公式与技能，不混合不同来源的数值。
- G 列职业技能文本是选位映射依据。隐藏的「本职技能」表有旧名称和不一致的名额，例如戏剧演员的自由名额，不能直接照搬标记网格。
- 多项科学、格斗和艺术等按各自位置分配。关闭技能专长时，退回不可用投入，并合并映射到同一基础技能的重复位置；开启后恢复完整位置。系统不以无关技能凑满八项。
- 非八项的扩展职业按原表保留实际数量；注明「至多」的位置可留空。「任意多种」艺术／手艺允许对多个专长投入职业点，仍受总点数、技能上限及兴趣点房规约束。学术自选位置限制在学问、科学、语言及相关学术技能中，具体领域仍由主持人审核。
- 动物辅助治疗师的重复段落、士兵的重复潜行各只计一次；交际花的「钳工」按锁匠归并，均附注说明。需主持人批准的催眠、灵媒、克苏鲁神话等替换保留原文，不自动执行。
- 驯兽、潜水等基础值读取人物卡，艺术／手艺和语言等采用对应技能族的基础值。马车驾驶、自行车驾驶、礼仪在来源中没有数值，暂显示 0；向这些技能投入点数前，须在「扩展技能基础值」解锁、切换手动并确认。保存后仍须通过主持人审核。锁按钮防止误触。
- 高中生的教育上限、相扑力士的力量和体型门槛进入制卡校验。来源中的额外体型骰不自动追加，以免重选职业时反复增加属性。

角色 JSON、结构化 Markdown 和房间存档均保留职业编号与手动基础值。切换职业时，符合新范围的投入保留，不适用部分退回相应点数池。

## 维护

结构化数据位于 `shared/coc-occupation-data.json`，目录元信息位于 `shared/coc-occupations.ts`，选位展开和旧卡兼容逻辑位于 `shared/coc-career.ts`。不要通过职业名称去重，也不要改变已有编号。修改数据后运行 `tests/coc-occupations.test.ts`，覆盖全部 229 项在两种专长模式下的分配、校验和导入导出。
