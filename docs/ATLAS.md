# 地图册与场景集

## 从剧本提取与导入

1. 打开「主持人工具集」中的「地图与场景」，点击「提取提示词、模板与教程」。
2. 复制提示词，连同剧本 PDF、文字或页图交给外部 AI Agent，说明所用规则与提取范围，并附上章节和页码。此步骤在站外完成，不调用站内 Gemini 接口。
3. 让 AI 输出包含单个 JSON 代码块的 Markdown 文件。地图用于记录地点布局、出入口与路线说明；每张地图可关联多个场景，也可建立不关联地图的独立场景。
4. 将结果保存为 `.md` 或 `.json`，在个人地图集中点击「导入地图集」，核对数量、来源与规则后确认导入。导入内容保存为独立副本，不会覆盖已有地图册。
5. 检查各场景的公开描述与主持人笔记，将隐藏线索、秘密与检定条件留在主持人笔记中，避免公开描述包含剧透。
6. 创建房间并担任主持人后，在个人地图集中点击「带入房间」。房间内保存独立副本。
7. 在房间工具栏打开「地图与场景」，按地图筛选或搜索场景，核对公开预览与私密笔记后点击「公布此场景」。系统仅将场景标题与公开描述发布到所有人的当前场景区。

## 手动编辑与存储限制

点击「新建地图册」创建资料集，使用「添加地图」建立地点，使用「添加场景」建立场景。选中某张地图后新建的场景默认归属该地图，也可在场景编辑页修改归属；删除地图会将所属场景转为独立场景并保留场景正文。修改完成后点击「保存地图册」，即可导出或带入房间。

个人地图集保存在当前浏览器的 IndexedDB 中，上限为 50 本（共 8 MiB），单本最多包含 50 张地图与 300 个场景。更换浏览器或设备前请先导出备份。房间地图集保存在服务端，仅当前主持人可读写，移交主持权后由新主持人接管。

Markdown 与 JSON 导出文件均包含主持人笔记，可再次导入。删除地图集不会清空房间内已公布的当前场景文本。

## 文件格式

外部 AI 提取格式顶层包含 `documentType: "atlas-source"`、`schemaVersion: 1` 与 `atlases` 数组。单册内 `maps[].key` 必须唯一，`scenes[].mapKey` 引用对应 `key` 或设为 `null`。未知文本填为空字符串，系统导入时自动补齐可选字段。

网站导出格式顶层为 `interlude-atlas-library`，单册为 `interlude-atlas`，包含持久编号与时间戳。导入时按整批校验版本与字段类型，同时检查引用关系和容量上限，全部通过后才会写入资料库。
