# 角色法术、装备与主持人备团

D&D 角色卡按 2014 或 2024 保存版次，房间内的角色、法术与装备须使用同一版次。未启用法术与装备模块的旧卡继续使用原有手填 AC 和物品列表。相关规则细节见 [法术与资源](DND-MAGIC.md) 与 [核心装备资料](DND-EQUIPMENT.md)。

## 制卡阶段配置

在角色卡打开「法术与资源」并点击启用。系统根据职业与等级提供可选法术列表、准备或已知法术名额，同时生成常规法术位与契约法术位，并记录生命骰和职业能力次数。法师需先将法术加入法术书，再勾选「已准备」；戏法与环阶法术分别计算名额。

「额外授予与自定义资源」用于记录种族与专长，或者子职和物品提供的额外法术及能力次数。填写来源后，可设置是否允许消耗法术位、仪式施展或不耗位施展，以及可用次数和恢复时机。次数填 0 代表随意施展；若仅允许消耗法术位或仪式施展，请关闭「授予不耗位施展」。

在「装备与负重」启用联动后，可从当前版次的装备目录添加物品。成捆弹药按实际支数计入（如目录中的一捆箭计为 20 支）。护甲、盾牌和武器需点击穿戴或持用后才生效，存放在容器内的装备需先取出。系统会校验单双手持握与盾牌的手数冲突，骑枪保留骑乘单手例外。

AC 按当前穿戴护甲或所选无甲防御公式计算，再计入已持用盾牌、额外加值与敏捷等临时属性修正。特殊装备的攻击与伤害加值，以及 AC 加值、额外熟练和同调要求需注明来源并交主持人审核。重量为空的条目会在界面提示待核对，钱币按 50 枚 1 磅计重，容器可提示重量与件数超限。

## 局内操作

开团后从房间工具栏打开「角色准备」。玩家可管理自己的角色，主持人可切换管理任意玩家角色。

- 选择法术、施法方式和实际消耗的法术位，点击「施放并记账」。服务端会校验准备资格与规则版次，同时检查剩余法术位和护甲熟练，并自动更新专注状态。2024 版在已有战斗行动顺序时，限制同一回合消耗一个法术位施法，推进回合后解除限制。
- 职业能力与自定义资源点击「消耗」扣减剩余次数，法术材料可填写本次消耗备注。
- 休息时勾选确认完成条件后点击结算。短休支持投掷生命骰及法师奥术回想；长休在 2014 版恢复至多一半生命骰，2024 版恢复全部生命骰。主持人可在「队伍总览」中选择多名成员批量结算休息。
- 装备穿脱与单双手切换，以及同调、容器收纳和弹药消耗均通过服务端实时同步。主持人可在局内从目录向角色发放装备；如需更改法术准备配置，需返回准备阶段并重新提交审核。
- 主持人在「场景与回合」的「行动与状态」面板选中玩家角色发起定向攻击时，可直接选择已持用的武器。命中加值与伤害骰由角色属性、熟练与魔法加值自动计算；使用弓弩等远程武器时需选择兼容弹药，命中与失手均消耗 1 发。使用轻型武器发起额外攻击时，默认不计入正属性伤害调整值。

## 主持人审核

「审核与制卡要求」面板会列出角色额外法术的来源与施法权限，同时显示自定义资源上限、恢复方式以及特殊装备加值与熟练来源。系统校验数值边界与同版目录，主持人确认本团允许这些额外授予后点击通过。

## 遭遇预案与伙伴归属

「主持人工具集」中的「遭遇预案」可在入房前使用。先在对应的个人 NPC / 怪物库建立资料，再新建预案，按波次添加参战资料快照与人数，填写奖励和主持人笔记。个人预案保存在浏览器 IndexedDB 中，支持导出为 JSON 或 Markdown 并重新导入。

进入相同规则与版次的房间后，将预案带入房间并切换到「本桌预案」，可关联房间内的已有场景。开团后点击「载入波次」即可将该波参战个体追加至本场遭遇（若勾选同步公布场景，仅发布场景公开描述）。个人库与房间预案库各上限 40 份（8 MiB），单份最多 20 波，每波最多 60 名参战者。

D&D 遭遇中的 NPC 或怪物个体可在「伙伴归属」中指定给一名玩家，用于管理魔宠、召唤物或随行同伴。主持人公开该个体后，所属玩家可记录其 HP 并代掷先攻，原始数据块模板与私密笔记仍仅对主持人可见。玩家离席或升任主持人时会自动解除伙伴归属。
