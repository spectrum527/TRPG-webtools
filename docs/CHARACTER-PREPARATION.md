# 角色法术、装备与主持人备团

角色卡按 2014 或 2024 保存版次；房间中的角色、法术和装备须使用同一版次。没有启用新功能的旧卡继续使用原有手填 AC 和物品记录。

## 制卡时准备

在角色卡中打开「法术与资源」，点击启用。职业与等级决定可选法术列表、名额、普通法术位、契约法术位、生命骰及职业次数资源。法师先把法术加入法术书，再选择「已准备」；准备型和已知型职业分别显示对应栏目。戏法和职业法术不混用名额。

「额外授予与自定义资源」用于记录种族、专长、子职或物品的例外。填写来源，再选择是否允许使用法术位、仪式或不耗位施展，以及次数和恢复方式。填 0 次表示随意施展，不表示没有施法权限；只授予耗位或仪式时应关闭「授予不耗位施展」。子职及专长不会因写了名称就自动获得全部效果。

在「装备与负重」启用联动，从当前版次目录加入物品。弹药按实际件数记录，目录的一捆箭会加入 20 支。护甲、盾和武器须点击穿戴／持用才生效，装在容器里的装备须先取出。双手武器、盾牌和单双手持握会校验手数；骑枪保留骑乘例外。

AC 采用护甲或所选无甲防御公式，再计有效盾牌与明确的额外加值。敏捷等临时属性修正也会影响派生数值。特殊物品的攻击、伤害、AC 加值及同调要求须注明来源。基础职业训练按版本提供；子职选择、专长等额外训练可明确添加并交主持人审核。

重量为空时不按零重量认定。界面显示已知重量小计并提示待核对；容器的重量、件数容量可提示超限，体积与物品形状仍须人工判断。钱币按 50 枚一磅计重。目录套组与其中每件物品不要重复记入同一行囊。

## 局内操作

故事开始后，从桌边工具打开「角色准备」。玩家管理自己的角色，主持人可选择任意玩家角色。

- 选择法术、施法方式和实际消耗的法术位，点击「施放并记账」。服务器校验准备资格、版次、剩余法术位与护甲训练，并更新专注。仪式按对应职业和版次判断资格。2024 在已有行动顺序时限制同一回合消耗一个法术位施法；回合推进后重新记录。
- 职业及自定义资源用「消耗」记账。它不会自动触发狂暴、变形、治疗等完整效果。法术成分可记本次使用说明，物品与费用另行扣除。
- 完成所需休息时间与条件后，勾选确认再结算。短休可指定生命骰；法师可填奥术回想恢复的环阶。2014 长休恢复至多一半生命骰，2024 全部恢复。主持人的「队伍总览」可对选定成员批量休息。
- 穿脱、单双手、同调、收纳和消耗通过服务端同步。主持人可以在局内从目录给予装备；改变魔法配置应返回准备阶段并重新审核。
- 主持人在「场景与回合 → 行动与状态」选中玩家角色后，可以在定向攻击中选择已持用武器。攻击加值与伤害由角色属性、熟练和魔法加值推导；弓弩等须选择弹药，命中与失手都消耗一份。类型明确不匹配的弹药不能选择；未知类型须主持人确认。轻型额外攻击须确认另一把武器的前置攻击和动作条件，默认不加正属性伤害调整值。

资源、装备与专注随角色存入服务器和全局 ZIP，清空一场遭遇不会补满法术位或资源。请求带状态版本和操作编号；同一请求重试不会再次扣减。多个窗口同时操作时，以服务器确认后的最新状态为准。

## 主持人审核

「审核与制卡要求」默认显示额外法术的来源、施法权限和次数，自定义资源上限／恢复，以及装备特殊加值与训练来源。批准针对当前人物卡版本。系统检查数值与同版目录，主持人确认剧本是否允许这些授予；两者都通过才能开始。

主持人私密日志保留施法详情与材料备注，公共记录显示进行了施法或资源操作。其他玩家不会取得该角色的完整法术配置、装备数值快照或私密备团资料。

## 遭遇预案与伙伴

「主持人工具集 → 遭遇预案」在入房前即可使用。先在对应的个人 NPC／怪物库制作资料，再新建预案，按波次加入资料快照和人数，填写奖励及主持人笔记。个人预案保存在当前浏览器的 IndexedDB，可导出 JSON 或 Markdown；两种文件都能重新导入。

进入相同规则与版次的房间后，将预案带入房间，再切换「本桌预案」。可在编辑预案时关联房间已有场景。故事开始后点击「载入波次」，将参战个体追加到当前遭遇；其他波次和私密笔记不会公布。再次载入同一波次要明确勾选确认，网络重试不会重复加入。若勾选同时公布场景，仅发布场景的公开描述。

每个个人／房间预案库最多 40 份、8 MiB；单份最多 20 波，每波最多 60 位参战者，当前遭遇仍受原有总人数限制。跨规则或跨版次的同编号资料不能覆盖。预案文件和全局 ZIP 含主持人私密内容，只交给有权读取的人。

D&D 遭遇中的 NPC／怪物个体可在「伙伴归属」指定给一名玩家，用于魔宠、召唤物或同伴。主持人公开该个体后，其所属玩家可记录 HP 与先攻；模板和私密笔记仍由主持人保管。离席或升任主持人会解除该玩家的伙伴归属。清空本场会移除伙伴个体，原模板和预案仍可再次载入；没有自动召唤、操控 AI 或跨场景单位模拟。

## 范围

本轮覆盖单职业核心施法与资源记账、常规装备数值及主持人准备流程。升级、兼职施法位、完整职业／专长效果、精通动作、装填动作次数、法术伤害与治疗、物品购置和货币交易仍由同桌裁定或手动记录。

规则依据及差异见 [法术与资源](DND-MAGIC.md)和[装备目录](DND-EQUIPMENT.md)。原人物卡 JSON／Markdown 与全局存档继续可读，新字段只在启用功能后写入。
