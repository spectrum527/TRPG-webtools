# D&D 2014 与 2024 制卡

创建房间时需选择 2014 或 2024 版次。人物卡与房间配置，以及 NPC / 怪物数据块和全局存档均记录所属版次，未标明版次的早期文件默认按 2014 版读取。两个版次的备团资料可在个人库中分别保存，并带入对应版次的房间。

## 熟练与属性分配

- 2014 版：按职业可选技能范围分配熟练，加两项自定义背景技能与种族熟练；出现重复熟练时可按规则补选同数量的替代技能。属性栏填写计入种族加值后的最终属性值。
- 2024 版：按 2024 版职业与种族范围分配技能及专精。选择内置的 2024 玩家手册背景时，两项背景技能固定授予（来源重合时只计一次熟练）；使用自定义或扩展背景时，由玩家填写两项技能并交主持人审核。属性加值来自背景列出的三项属性（分配 +2 / +1 或三项各 +1），填写计入加值后的最终属性值。

## 被动察觉

在角色卡「属性与状态」页开启被动察觉后，面板会显示 `10 + 当前感知（察觉）检定调整值`，自动计入熟练、专精与生效中的角色调整。情境具有优势时加 5，具有劣势时减 5，由主持人判定。
