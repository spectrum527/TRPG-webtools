# D&D 2014 与 2024 制卡

建房时选择版次。人物卡、房间配置、NPC／怪物数据块和全局存档均保留版次。早期文件省略版次时按 2014 读取。两个版本的卡可分别存入个人备团库，并带入对应版本的房间。

2014 版沿用职业技能、两项自定义背景技能、种族熟练和重复熟练补选。2024 版改用该版职业和种族的技能范围及专精等级。选择 2024 版玩家手册的背景时，两项技能固定授予。来源重合时只计一次熟练。其他背景的两项技能由玩家按来源填写，交主持人审核。

属性栏填写最终数值。2014 版核对种族加值，2024 版核对背景列出的三项属性，再分配 +2 与 +1，或各 +1。2024 版使用旧种族时，属性加值仍来自背景。起源专长及其效果、分支职业和扩展选项由主持人按本桌规则核对。

在角色卡的「属性与状态」开启被动察觉后，会显示 10 加当前感知（察觉）检定调整值。这个数值计入熟练、专精和生效中的角色调整。两版都在情境优势时加 5，劣势时减 5。主持人按场景决定是否使用被动察觉。

## 规则依据

制卡和被动察觉取自用户提供的《DND5e规则库》整理版。可在其中按以下条目定位。

| 规则                | 整理库中的条目                                                                            |
| ------------------- | ----------------------------------------------------------------------------------------- |
| 2014 被动察觉       | `玩家手册/属性值应用/属性检定` 中的「被动检定」                                           |
| 2024 被动察觉       | `玩家手册2024/创建角色/第五步：丰富细节` 与术语汇编 `chm-f2b66a358d67-s002`               |
| 2014 熟练补选       | `玩家手册/个性与背景/个性与背景`，分节 `chm-3ae502e0347f-s003`                            |
| 2024 背景与种族     | `玩家手册2024/角色起源` 的各背景、种族页，以及 `玩家手册2024/创建角色/第三步：确定属性值` |
| 2024 职业熟练与专精 | `玩家手册2024/角色职业` 下各职业核心特质表及等级特性                                      |
