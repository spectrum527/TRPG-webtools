# D&D 法术书与专长

在主持人备团中打开「法术书」或「专长」，先选择战役使用的 2014 或 2024 版次。在「规则目录」中可按中文名、英文名、效果或出处搜索，法术还可按环级和职业筛选；「资料来源」默认选择核心规则。打开条目可查看法术参数、专长前置条件和规则原文；同名条目在不同版次分别保存，请以战役所选版次为准。

使用「加入法术书」或「收藏专长」保存常用条目，可在「我的法术书」或「我的专长」中查看和移除。清单保存在当前浏览器的本站点中，不会自动发送到房间。可导出 JSON 或可阅读的 Markdown 备份；两种格式均可重新导入。导出包含**当前版次和当前种类**的个人清单，其他版次或种类需要分别切换并导出。导入时按条目编号合并，遇到与已保存的其他版次或来源共用编号的条目会拒绝此次保存。换浏览器或清除站点数据前，请先导出备份。

## 资料范围

资料转换自所提供的已处理 D&D 规则库的法术与角色实体索引，不读取原始 CHM 或 PDF。默认查看对应版次的玩家手册核心资料：

| 版次 | 核心法术 | 核心专长 |
| ---- | -------: | -------: |
| 2014 |      361 |       42 |
| 2024 |      391 |       75 |

2014 数据包另外保留可确认版次的扩展及第三方条目，并标注各自来源类别；它们与核心资料分开。原索引中版次未确认的 1 条法术和混合版次的 7 条专长索引没有归入上述两版。书名、来源编号及规则库内相对定位随条目保留，相对定位用于回查提供的资料库，并非网站内的链接。来源标记沿用规则库的分类。

原索引没有确定的字段保留为空，不能据此认定不存在。法术职业按整理库原文和索引转写：部分 2014 条目包含后来补充的奇械师，不能视为仅依据原版玩家手册重建的职业法术表。专长前置条件只在原文中能明确划出边界时单独列出，完整规则文字仍可查看；索引中标注的提取边界或待核验状态也会保留。查询结果用于辅助主持人阅读，不自动判断角色资格或执行规则效果。

## 重新生成数据

在项目目录运行以下命令，将路径替换为已处理规则库的目录：

```sh
python3 scripts/build-dnd-reference.py /path/to/processed-rules-library
```

脚本读取规则库的法术和角色机器索引，生成 `public/rules/dnd-2014.json` 与 `public/rules/dnd-2024.json`；相同输入会产生相同结果。生成内容不含本机绝对路径。
