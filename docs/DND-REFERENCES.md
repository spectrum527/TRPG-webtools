# D&D 法术书与专长

在「主持人工具集」切换 D&D 2014 或 2024 版次后，可打开「法术书」或「专长」查阅规则目录。目录支持按中英文名称、效果正文或出处搜索，法术还可按环阶与职业筛选。「资料来源」默认勾选核心规则，扩展与第三方来源可单独勾选。同名条目在两个版次中独立保存。

点击「加入法术书」或「收藏专长」，即可把常用条目存入「我的法术书」或「我的专长」。个人清单保存在当前浏览器的本地存储中，可导出为 JSON 或 Markdown 备份并重新导入；每次导出对应当前所选版次与类别，更换设备或清理缓存前请分别导出。

## 收录范围

目录数据转换自已处理规则库的法术与角色实体索引，保留书名、来源编号及规则库内相对路径。两版核心玩家手册收录数量如下。

| 版次 | 核心法术 | 核心专长 |
| ---- | -------: | -------: |
| 2014 |      361 |       42 |
| 2024 |      391 |       75 |

2014 版数据包另含已确认版次的扩展及第三方条目（按来源类别区分）；部分 2014 法术条目包含后续补充的奇械师职业标记。专长条目展示前置条件与完整规则原文。

## 重新生成数据

在项目根目录执行以下命令，并将路径替换为已处理规则库的根目录。

```sh
python3 scripts/build-dnd-reference.py /path/to/processed-rules-library
```

脚本读取规则库中的法术与角色机器索引，生成 `public/rules/dnd-2014.json` 和 `public/rules/dnd-2024.json`。
