# D&D 核心装备资料

装备目录来自所提供规则库的已处理正文与机器索引，按 2014 和 2024 分成两份，不按名称跨版合并。每条资料保留来源书、来源编号、规则库内相对路径、表格和行号；相对路径用于回查提供的规则库，不是网站内的链接。

2014 的捕网列为特殊武器，源表不提供伤害；2024 的捕网列在冒险用品，火铳和手铳列在武器表。2024 的武器精通名称与说明保留源文，能否使用须按角色特性核对；目录不会自动触发精通或其他战斗效果。魔法物品的额外加值、调谐要求和效果需要按具体物品与本团规则填写，不由普通装备目录推断。玩家手册冒险用品中列出的治疗药水及卷轴保留原有条目。

## 数值使用边界

- `weightLb` 和 `costCp` 是源表**所列一份**的重量和价格。弹药及其他明确按捆出售的条目用 `quantityPerPack` 给出一份的数量，例如 20 支箭共重 1 磅；单支重量应按份数换算，不能把整包重量当成每支重量。价格以铜币为单位，整包价格也不代表每发价格。
- 2024 套组表中标出的重量对应整套装备，若把套组和其中每件物品同时逐项记录，应避免重复计算。2014 套组原文提供价格和内容，但没有给成套重量，目录中的重量保持未知。
- 水袋的源表只给出盛满后的 5 磅：`weightLb` 为未知，`weightWhenFullLb` 为 5。重量栏的短横线、空白和“多类”不当作零重量；可回看 `weightText`。
- 护甲的 `baseAC` 是基础值；`addsDex` 表示是否加敏捷调整值，`dexCap` 是上限。只有 `addsDex` 为 true 且 `dexCap` 为空时，才表示敏捷调整值无上限。重甲不加敏捷；盾牌加值另计。
- 容器的重量、体积和特定数量容量分别记录，原文保留在 `capacityText`。例如 2014 箱子注明 300 磅和 12 立方尺，2024 箱子只注明 12 立方尺；不能将前者的重量上限自动带入后者。
- 字段为空表示原资料未给、不能明确提取或不适用，不能一律视作零或否。2014 战镐的机器索引属性栏为空，但已处理的玩家手册逐页文本第 149 页明确标为短横线，目录据此记录无属性并保留回查路径。骑枪的持用条件和捕网的特殊规则需要核对原文；2024 骑枪注明骑乘时可不按普通双手要求处理。
- 2014 弩矢与投石索弹丸的机器索引将 1½ 磅扁平化为 `11/2磅`；目录依据已处理的玩家手册逐页文本第 150 页将两行记录为每份 1.5 磅，同时保留原始文字与回查路径。

## 重新生成

在项目目录运行以下命令，将路径替换成已处理规则库的根目录：

```sh
python3 scripts/build-equipment-catalog.py /path/to/processed-rules-library
```

脚本读取装备实体索引、机器表格和已处理 Markdown 正文，生成 `public/rules/equipment-2014.json`、`public/rules/equipment-2024.json`。2024 弹药在冒险用品的嵌套表中，单独按表行提取；2014 七种套组从对应正文提取。同一输入可重复生成相同结果，输出不含本机绝对路径。结构与校验入口为 `shared/equipment-catalog.ts`。
