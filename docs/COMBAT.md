# 场景与回合的战斗操作

在房间右侧「场景与回合」的「行动与状态」面板管理参战者与先攻顺序，并记录 HP 和状态。D&D 5e 房间按建房时所选的 2014 或 2024 版运行，CoC 房间按第 7 版运行。D&D 版次差异与资料兼容性见 [D&D 2014 与 2024 制卡](DND-EDITIONS.md)。

## 加入参战个体

1. 在「主持人工具集」选择规则，创建或导入 NPC / 怪物资料。进入对应规则的房间担任主持人后，点击「带入当前房间」。
2. 在「行动与状态」选择房间资料与生成数量（单次 1 至 20 名），点击「加入参战」。同一模板生成的多个个体各自独立记录 HP、状态与能力次数。
3. 玩家载入人物卡后自动列入参战名单。若个体当前 HP 未知，可手动填入，或点击「将当前 HP 填为上限」；敏捷未知时可补填敏捷或使用「手填行动值」。
4. 全员准备并通过人物卡审核后，主持人开启故事，即可掷先攻、生成行动顺序并使用定向伤害结算。

单场战斗最多容纳 60 名参战者。参战个体保留加入时的资料快照，删除房间库模板不会移除已上场的个体；清空本场记录会移除 NPC、重置先攻顺序与战斗笔记，保留玩家的 HP、伤势、死亡豁免计数和自动化开关。清空战斗不会让死亡角色复活。

## 先攻与行动顺序

### D&D 2014 与 2024

玩家可在「本场战斗」中点击「掷先攻」，DM 也可选中 NPC 或怪物单独代掷。先攻按 `d20 + 敏捷调整值 + 额外先攻加值` 计算（支持优势与劣势）。DM 可在目标掷先攻前标记「受突袭」。

| 版次 | 受突袭处理方式                                                                                        |
| ---- | ----------------------------------------------------------------------------------------------------- |
| 2014 | 按正常方式掷先攻。受突袭者首回合无法移动或行动，该回合结束后才可使用反应；DM 点击「下一位」时解除标记 |
| 2024 | 掷先攻时具有劣势（可与已有优势抵消），排定顺序后正常行动                                              |

DM 点击「生成顺序」时，已掷出的结果保留，未掷先攻的参战者自动补掷。手填行动值优先于掷骰结果，同值按当前名单顺序排列。点击「下一位」推进回合；点击「重新排定」会保留当前行动者与轮次，后续回合按新顺序进行。

### CoC 7

KP 点击「生成顺序」即可按 DEX 从高到低排列。勾选「枪械已准备好」使行动值加 50，手填行动值优先。点击「重新排定」会按最新 DEX、枪械状态与手填值从第 1 轮首位重新开始。

## 自动扣减生命值

「自动扣减生命值」默认关闭。开团后主持人可打开该开关，选择目标与结算方式，由服务端统一掷骰、计算伤害并更新玩家人物卡或 NPC 个体的 HP。

### D&D 定向攻击

1. 在「行动与状态」选中攻击者，打开「攻击与伤害」下的「攻击命中后结算」，选择「攻击目标」。工具会自动读取目标 AC。可手填完整攻击加值，也可点击数据块中的攻击快捷项带入；若攻击者是已启用装备联动的玩家角色，可直接选择已持用武器并自动扣减对应弹药。
2. 填写命中后的纯伤害骰式（如 `2d6+3`），按本次伤害属性选择正常或免疫，也可应用抗性与易伤（含先抗性后易伤）。
3. 点击「攻击并自动结算」。未命中仅记录检定日志；自然 20 重击会将伤害骰数量翻倍（固定加值只计一次）。抗性减半向下取整，易伤翻倍，免疫归零。伤害先扣减临时 HP，剩余部分扣减当前 HP（最低降至 0）。

单次定向攻击结算一种伤害，复合伤害可用「直接结算伤害」追加。若目标 AC 未填写，请改用普通攻击检定；若目标当前 HP 未填写，命中会记入日志，待补填 HP 后手动处理。

### CoC 近战对抗与伤势

在「近战对抗」中选择进攻方与防守方（防守方可选闪避或反击），带入资料卡技能或手填百分比，并可为双方各选一颗奖励骰或惩罚骰。闪避同档时防守方胜，反击同档时进攻方胜，双方均失败则无伤害。

开启自动扣血后，填入「进攻方普通伤害」（选择反击时另填「反击普通伤害」），极难或大成功进攻命中则使用「极难命中伤害」（留空时先记录命中，可稍后用直接伤害补结算）。系统默认读取目标资料卡中的护甲（玩家默认护甲为 0），也可用「本次护甲覆盖」临时指定。若 NPC 护甲未知且未填覆盖值，工具会保留检定结果，待确认护甲后再结算。

扣除护甲后，单次伤害达到目标 HP 上限一半时自动标记重伤；重伤状态下 HP 降至 0 标记昏迷与濒死；单次伤害达到或超过 HP 上限时标记死亡。没有重伤的角色 HP 归零时只会昏迷。关闭自动扣血时点击「掷骰并比较」，仅比较对抗胜负而不扣减 HP。

### 直接伤害

环境伤害或已判定命中的补结算，请选择「直接结算伤害」（CoC 为「伤害结算」）。选定已填写当前 HP 的目标，输入伤害骰式或固定数值，点击「掷伤害并扣血」。若此前已自行算好抗性或护甲减免，D&D 请选「正常伤害」，CoC 请将「本次护甲覆盖」填为 0。

## 辅助掷骰与状态管理

- 专注豁免：保存当前专注法术，填入本次伤害值与体质豁免加值。DC 取 10 与伤害一半（向下取整）中的较大值，2024 版上限为 30。豁免失败后由 DM 点击确认结束专注。
- 死亡豁免：HP 为 0、未稳定且未死亡时可掷 d20。10 及以上记一次成功，低于 10 记一次失败，自然 1 记两次失败，自然 20 恢复 1 HP。手动模式下点击「确认记录此结果」应用；三次成功稳定并清空计数，三次失败标记死亡。已经排定顺序时，每轮最多记录一次死亡豁免。
- 能力与资源：玩家角色的法术位与职业资源在「角色准备」面板记账；参战个体的独立能力次数与充能 d6，以及传奇行动点数、状态标签和临时 HP 可在本面板手动记录，修改后点击「保存本场记录」。

## 伤势与死亡自动化

「自动扣减生命值」同步处理明确伤害造成的 HP 和伤势。「自动伤势检定」是独立开关，默认关闭；开启后，由服务端掷骰并直接记录结果：

- **CoC 7**：造成重伤时进行体质检定，失败则昏迷。进入濒死后，从下一轮结束时起，每轮末进行体质检定；成功维持濒死，失败标记死亡。缺少体质或生命上限时，会提示主持人补充或手动裁定。
- **D&D 2014／2024**：角色回合开始时进行死亡豁免。恢复 HP 会解除因 0 HP 造成的昏迷、濒死并清除计数；稳定仍保持 0 HP 与昏迷。0 HP 时受到有效伤害增加一次失败，重击增加两次；临时 HP 不免除已经处于 0 HP 时的失败计数。巨量伤害按生命上限判定即时死亡，2024 版还处理生命上限为 0 的死亡。
- 普通 D&D NPC／怪物默认在 HP 归零时死亡。主持人可为特殊个体勾选「0 HP 时使用死亡豁免」；玩家角色始终使用死亡豁免，获授权伙伴默认按角色处理。
- 昏迷与死亡会结束 D&D 专注。死亡后不能通过普通加血或休息复活；须由主持人在「治疗与恢复」确认复活条件后恢复为 1 HP。

自动回合检定按基础规则处理。涉及额外加值、优势／劣势、替代死亡效果、击昏或其他特殊能力时，可关闭自动检定或自动扣血，由主持人核对后手动记录。普通骰子与无目标检定不会自行改变伤势。

### 手动修改 HP

玩家的生命值按钮、主持人的参战者编辑、伙伴 HP 都使用同一确认流程。进行中房间里，将 HP 改至 0 或触发濒死／死亡时，弹窗显示原值、新值和预计状态：

- 取消不会保存数值；确认期间角色或战斗状态变化时，必须重新核对。
- 自动扣血开启时，确认后同步伤势；关闭时只保存 HP 及手动填写的标记。
- 手动修改按 HP 的实际下降量判断，不再次扣除护甲或临时 HP。直接填写 0 不能表达 D&D 的溢出伤害，巨量伤害应使用伤害结算；主持人也可在弹窗中明确裁定死亡。

### 治疗与恢复

选中角色后展开「治疗与恢复」。先在检定工具或线下完成检定，再由主持人确认适用条件：

- D&D：确认医药检定成功后稳定伤势。
- CoC：急救成功通常恢复 1 HP 并唤醒；濒死者先暂时稳定，仍为 0 HP。医学治疗须在必要急救之后进行，确认成功后由服务端掷 1D3 恢复 HP。每次新增伤害后可重新处理一次急救与医学治疗，重试同一请求不会重复加血。
- 自然恢复、治疗所需的游戏时间、器材、急救后的持续观察及特殊能力由主持人判断，不按现实时间自动推进。CoC 的重伤标记在恢复至生命上限一半时清除。

伤势、开关与检定进度随房间保存，支持刷新、重连和全局存档恢复。自动检定和确认处理仍遵循玩家／主持人权限与暗骰可见范围。

## 可见性与存档保存

NPC 与怪物默认对玩家隐藏。公开个体后，玩家仅可见其别名、行动值与公开状态；若 DM 将个体指定为某位玩家的伙伴归属，该玩家可额外查看并修改其 HP 与先攻。主持人暗骰在玩家端仅显示暗骰占位，真实点数与结算明细仅对当前主持人可见。

战斗状态与参战个体，以及先攻顺序和回合进度均随房间实时写入服务端，并包含在导出的[全局存档](SESSION-ARCHIVE.md)中。若定向结算因网络波动提示「本次操作未确认完成」，核对日志后可点击「重试本次操作」，服务端会按请求编号防止重复扣血。
