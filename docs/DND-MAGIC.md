# D&D 角色法术与资源

角色卡启用法术与资源管理后，通过 `dndMagic` 字段保存已选法术编号、准备与已知列表和法师法术书，并记录已用法术位、生命骰与职业能力次数。未启用该模块的旧卡保持原有字段不变。

## 法术选择与施展

2014 版按职业区分已知施法与准备施法；2024 版统一按职业等级表读取准备名额。法师需先将法术录入法术书，再从中勾选已准备法术；抄录法术时会显示基础耗时与金币费用。战士（奥法骑士）与游荡者（诡术师）可在达标等级启用对应施法子职（2014 版同时检查跨学派法术名额）。

常规法术位为一至九环，升环施法时按实际消耗的环阶扣减。邪术师 / 魔契师使用独立的同环阶契约法术位，6 至 9 环玄奥秘法各自单独记录使用次数。仪式施法按版次、职业与法术属性校验资格，施展时不消耗法术位。施法豁免 DC 与法术攻击加值自动读取角色当前生效的施法属性与熟练加值；施展专注法术时自动更新角色专注记录。

种族、专长或物品提供的法术，以及职业特性或主持人额外授予的法术，可在「额外授予与自定义资源」中记录来源与施法方式，并设定可用次数、恢复时机和施法属性。2024 版核心职业自带的猎人印记与至圣斩，连同寻获坐骑与荒野伙伴（寻获魔宠），以及联络宗主（异界探知）和创生圣言法术均已内置，不占用常规准备名额。

## 审核与休息恢复

角色卡审核页会展示法术名额、法术位余量与生效 AC，同时列出额外授予法术、自定义资源和装备特殊加值。在准备阶段修改法术配置或特殊装备后，需重新提交主持人审核。

- 短休：可投掷生命骰恢复 HP（计入体质调整值），邪术师 / 魔契师恢复契约法术位，符合资格的角色可执行奥术回想或秘法回流。
- 长休：恢复全部常规法术位与契约法术位，重置每日奥术回想额度。2014 版长休恢复已消耗生命骰至多达角色总生命骰的一半（向下取整，至少 1 枚）；2024 版长休恢复全部已消耗生命骰。
- 手动恢复：主持人可选择指定法术位或生命骰，也可选择职业次数与自定义资源，填写恢复数量与原因后单独补回已消耗额度。

## 规则依据

- 职业等级表与法术名额取自整理库 `05-机器索引/角色/class_level_tables.jsonl`，奥法骑士与诡术师核对两版子职页面（三级奥法骑士准备名额为 3 道）。
- 2024 版魔契师法术列表按职业法术表读取；秘法回流恢复上限按[官方英文基本规则](https://www.dndbeyond.com/sources/dnd/br-2024/character-classes)与[官方版本对照](https://www.dndbeyond.com/posts/1756-2024-warlock-vs-2014-warlock-whats-new)，取最大契约法术位数量的一半（向上取整），20 级魔能掌控恢复全部契约法术位。
